# 3명 · 2일 작업 계획

뼈대(파서·화면·샘플·테스트·배포)는 이미 동작한다. 이틀 동안은 **실제 데이터에서 잘 잡히게 다듬기**와 **발표 완성도**에 집중한다.

## 대회 전날까지 (중요)

- [ ] 각자 **Google Takeout으로 Gmail .mbox 요청** (takeout.google.com → "메일"만 선택). 준비에 몇 시간~며칠 걸린다.
- [ ] 각자 카카오·네이버 "연결된 서비스 관리" 화면을 복사해서 텍스트로 저장해두기 (개인 파일, 커밋 금지)
- [ ] Settings → Pages → Source = GitHub Actions 설정

## 역할 분담

파일이 겹치지 않게 나눴다. 각자 자기 파일 위주로 수정하면 충돌이 거의 없다.

| 사람 | 담당 | 주로 만지는 파일 |
| --- | --- | --- |
| **A — 메일 파서** | 실제 메일에서 놓치는 것/잘못 잡는 것 고치기, 금액 추출 정확도 | `src/lib/mime.ts`, `detect.ts`, `mbox.ts`, `*.test.ts` |
| **B — 서비스 사전 + 연결 서비스** | 서비스 사전 50개 이상으로 늘리기, 해지 링크 직접 눌러 검증, 카카오/네이버 붙여넣기 실제 화면으로 테스트 | `src/data/services.ts`, `src/lib/connected.ts`, `match.ts` |
| **C — 화면 + 발표** | 결과 화면 꾸미기, 모바일 확인, 금융 안내 문구, 발표 자료·데모 시나리오 | `src/components/*`, `src/styles.css`, `App.tsx` |

규칙: 파서를 고치면 실패하던 사례를 **테스트로 먼저 추가**하고 고친다 (`npm test`). 실제 메일 내용은 테스트에 넣지 말고 가짜로 바꿔서 넣는다.

## 넣으면 좋은 것 (시간 남으면)

- 결과를 이미지/텍스트로 복사해서 공유 ("나 매달 74,190원 새고 있었음")
- 서비스별 "해지 방법" 단계 안내 (앱에서만 해지되는 서비스 등)
- 결제일 캘린더 (.ics 내보내기)로 무료체험 종료일 알림
- Outlook/다음 메일 내보내기 형식 지원

## 데모 시나리오 (3분)

1. 문제: "구독 몇 개 하세요? 매달 얼마 나가는지 아세요?" — 대부분 모른다.
2. 해결: 앱 설치도, 문자 권한도 없이 웹사이트에 메일만 넣으면 된다. **서버가 없어서 메일이 밖으로 안 나간다.**
3. "샘플로 체험하기" → 결과 화면: 확인된 월 구독료, 무료체험 곧 결제 경고, 카카오로 가입하고 잊은 서비스
4. "해지하기" 누르고 체크 → 연간 절약액이 올라간다.
5. 금융 점검 탭: 메일에 안 잡히는 카드 자동납부는 어카운트인포로 한 번에, 광고 전화는 두낫콜로.
6. 마무리: 팀원 실제 데이터 결과 ("저는 한 달에 OO원 새고 있었습니다").
