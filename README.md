# Money — 잊고 있던 구독, 웹사이트 하나로 정리

메일함과 카카오·네이버 "연결된 서비스" 목록을 넣으면, 지금 돈이 나가고 있는 구독과
잊고 있던 계정을 찾아서 해지 링크까지 한 화면에 보여주는 웹사이트.

- **문자 권한 X, 앱 설치 X, 서버 X** — 정적 웹사이트 하나. 모든 분석은 브라우저 안에서 끝난다.
- 금융(계좌 자동이체·카드 자동납부·광고 전화)은 직접 연동하지 않고 **어카운트인포·두낫콜** 공식 사이트로 안내한다.

## 기능

| 단계 | 입력 | 하는 일 |
| --- | --- | --- |
| ① 메일 | `.mbox`(Gmail Takeout) · `.eml`(네이버 메일) · 메일함 목록/원문 붙여넣기 | 결제·정기결제·무료체험·해지 메일을 찾아 서비스별 금액·주기 추정 |
| ② 연결된 서비스 | 카카오/네이버 "연결된 서비스 관리" 화면 복사·붙여넣기 | 소셜 로그인으로 가입한 서비스 목록 정리, 유료 서비스 표시 |
| ③ 금융 점검 | — | 어카운트인포(자동이체·카드 자동납부·내카드한눈에), 두낫콜 바로가기 + 체크리스트 |
| 결과 | — | 확인된 월 구독료 / 유료일 수도 있는 것 / 해지 링크 / "정리 완료" 체크 → 연간 절약액 |

헤더의 **"샘플로 체험하기"** 버튼으로 가짜 데이터(`public/samples/`)를 넣어 전체 흐름을 바로 볼 수 있다. 발표 데모용.

## 시작하기

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # 파서 단위 테스트 (vitest)
npm run build      # 타입체크 + 프로덕션 빌드 → dist/
npm run samples    # public/samples/ 샘플 데이터 다시 만들기
```

Node 22.12 이상 필요.

## 배포

`main`에 푸시하면 GitHub Actions가 GitHub Pages(`https://teamjegal.github.io/Money/`)에 배포한다.
**최초 1회**: 레포 Settings → Pages → Source를 **GitHub Actions**로 바꿔야 한다.

## 판단 규칙 (발표 때 설명용)

- **결제 중**: 결제/영수증/정기결제 메일이 있음. 결제일 간격이 25~35일이면 "매월", 350~380일이면 "매년".
- **무료체험**: 체험 시작 메일만 있음 → 곧 결제될 수 있음.
- **유료일 수도**: 결제 메일은 없지만 사전에 유료 상품이 있는 서비스 (연결된 서비스 목록에서 발견).
- **해지됨**: 마지막 결제 이후에 해지 메일이 있음.
- **계정만 있음**: 무료 서비스 또는 사전에 없는 서비스.
- 사전에 없는 발신자는 "정기결제·구독·체험·해지" 메일만 인정한다 (일반 쇼핑 주문은 구독이 아니므로). `(광고)` 메일은 제외.
- 달러 결제는 1달러 = 1,400원으로 환산하고 "(추정)"으로 표시.

## 개인정보 원칙

- 서버·DB·분석 도구 없음. 메일 내용은 네트워크로 나가지 않는다.
- 분석 결과는 저장하지 않는다 (새로고침하면 사라짐). "정리 완료" 체크만 이 브라우저에 저장.
- 실제 개인 메일 파일은 커밋 금지 (`.gitignore`에서 `*.mbox`, `*.eml` 차단).
